## 小红书小工具离线包（minitool-zip-builder 1.8.0）
- skill 解压在 `.skill/minitool-zip-builder/`；构建脚本 `tools/build_minitool.py`，产物 `minitool/shujing-minitool-v4.0.28.zip`（0.67 MiB），校验摘要 `minitool/校验摘要.md`。
- **关键坑 1（别改回去）**：脚本必须打包成**单个** `assets/app.js`。源码里大量「前文件顶层代码引用后文件才声明的函数/常量」（figCubic / drawEpicWorld / drawBlazeWorld / BLAZE），拼成一个 <script> 靠整体提升没问题；切成多个 src 会 ReferenceError，实测开局炸 5 处，且静态扫不全。
- **关键坑 2**：src 全是 CRLF。文本模式 read 会把 \r\n 吞成 \n，改掉题目模板字符串里的换行；锚点匹配必须先归一到 LF、打完补丁再还原回 CRLF。
- **关键坑 3**：`__BUILD_VER__` / `__NEWS_VER__` 占位符不只在外置的 index.html，也在 73_version.js / 55_boot_news.js 里，bundle 后必须一并替换，否则界面直接贴出占位符。
- 改写规则集中在 build_minitool.py 的 PATCH_JS / PATCH_RE / PATCH_CSS；src/ 保持联网版不变，网页版与小工具版同一份源码。
- Chrome 61 基线：53 处 clamp/min/max 补了前置降级声明；:root 变量走 @supports 双份 + orientation 媒体查询近似 --vmin/--vmax。
- 在线文档新增能力：window.xhs.AI（平台对话模型，内测需加白）。AI 详解已接它；视觉识别（看图识题）平台不支持，已停用。
