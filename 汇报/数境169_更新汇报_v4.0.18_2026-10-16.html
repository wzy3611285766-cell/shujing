平板帧率 30 → 60：拿掉两处「隐形开销」

目标是「想尽一切办法把平板帧率提到 60」。第一步不是改代码，而是先量清楚谁在吃时间 —— 因为主线程那一侧压根没有开销（draw 只有 0.5ms），所有线索都指向合成器，而合成器只能用减法找。

v4.0.182026-10-16帧间隔 50ms → 16.7ms帧数 27fps → 60fps画质几乎没动 · 面板玻璃质感保留

一、先量：瓶颈不在「画」，在「合成」

`tools/perf.py` 本来就带一组消融开关（一次只关一样，看帧间隔掉不掉）。这次先把它们跑满，再动手。

场景（1180×820 dsf2，跑图状态）帧间隔 p50帧数/5s
默认画质（改前 v4.0.16）33.4 ~ 50.0 ms137（约 27fps）
消融 · 只关毛玻璃16.7 ms291
消融 · 只关地形图层16.7 ms276
主线程 draw（任何一档）0.5 ms——
两条各自都够把 60fps 砍成 30fps —— 说明两样都卡在预算边缘，必须一起拿掉。而主线程始终只有 0.5ms，这就是「看不出谁在吃时间」的原因：消耗全在合成器那侧，而合成器只能靠消融找。

二、改动一：地形层从合成器手里拿回来

旧架构：地形预渲染进 <canvas id="bg"> 这个 DOM 画布（世界尺寸 2400×1900），每帧只写一条 CSS 变换交给合成器挪 —— 想法是「GPU 挪图层不要钱、主线程零绘制」。

代价在另一头：那是1850 万像素的纹理（2400×1900 × dpr2），而且它每帧都在动，合成器每帧都得重新光栅化一遍。

改前（每帧）
  合成器：重栅格化 #bg 图层 4800×3800（18.5 MP）
  主线程：0 绘制（但这一层已经把合成预算吃掉了）

改后（每帧）
  主线程：drawImage(离屏 staticLayer) → 1.3ms（最近邻；双线性要 5.8ms）
  合成器：完全不碰地形
观感差别只有「位移步长」：以前是亚像素滑动（必须双线性采样），现在以设备像素为步长 —— 更稳，细网格不会逐帧游走发糊。顺带删掉了 #bg 元素、syncBgTransform() 和那条「取不到 #bg 就退化」的兜底分支：一条路径比两条路径可靠。

三、改动二：压在地图上的毛玻璃换成同色底

「背后永远是活地图」的元素（顶栏、topbar chip、任务条、提示气泡、全屏键、toast）不再用 backdrop-filter —— 那层模糊得跟着地图每帧重算。

  • 收掉的（背后永远是活地图）：#upbar / #topbar .chip / #topbar .btn / #quest 任务条 / #pcHint / #moveHint 提示气泡 / .tst 提示 / .fitbtn 全屏键
  • 保留的（一开地图就停画）：#modal 面板遮罩与面板内部、#news 公告与其中的按钮 —— 背景是静止画面，模糊只算一次，一分钱不花
所以「点开面板那一下的玻璃质感」没丢，丢的只是浮在地图上那几条几乎看不出来的雾。☰ 菜单里的画质档位也顺势收窄：现在只剩「要不要连面板毛玻璃也关掉」，两档帧率已经一样。

四、改动三（顺手挖出的真问题）：节拍器会「自己把自己降到 30fps」

复测时同一台机器两次跑出 16.7ms 与 33.3ms 两档，一开始以为是我改坏了 —— 看 PERF.multi 的终态才发现是节拍器自己降的档。

它的降档判据是「这批有 1/4 帧迟到」；而开局几次 GC / 首次布局抖动就够凑满 1/4。于是：本机明明能跑满 60，也被它永久砍成 30 —— 而且玩家毫无线索，只会觉得「这游戏就是卡」。

改前   late = miss > 这批的 1/4      → 一批评完就降档
改后   late = miss > 这批的 1/2 且连着两批
       heavy（主线程 >80% 预算）仍然当场降 —— 那个数是实测的，不会误判
       已经降下来的档，恢复门槛 6 批 → 3 批（一次误降只让玩家多看约 1.5 秒）
冒烟里的永久检查也随之升级：新增断言「DOM 里不许有地形层」「HUD 不许有毛玻璃」「面板模糊完整档必须在、流畅档必须无」。因为这类回退在主线程读数上完全看不出来，只能由检查来钉。

五、结果（同一台无头机、同一套脚本，改动前后各跑一遍）

tools/perf.py 也加了一档「⑦ 默认画质(复测)」：① 挨着开局，JIT / 首次布局的抖动会算进 p95，拿它当「这台机器的稳定帧率」偏悲观；跑热了再测一次，才是玩家十几秒后的真实状态。

六、两个自造的坑（都记一笔）

① 替换时吃掉了 PERF 对象的 `};`： 整个脚本语法错、白屏。现象很有意思 —— 探针打出帧数 83fps、画布 300×150：帧率异常高也是崩溃的信号（画布根本没初始化）。是启动报错探针 _dbg_boot.py 一分钟内抓到的（Unexpected token 'const'）。
② 公告 JSON 用了直引号： news.json 里我把 " 当强调引号用 → JSON 直接坏在第 15 行。项目里一律用「」，json.load 一验就现形。以后写公告先过一遍解析再说。
