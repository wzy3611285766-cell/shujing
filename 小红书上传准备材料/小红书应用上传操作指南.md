## 二、上传流程

### 步骤 1：打开小工具上传页

小红书的小工具上传入口在创服平台的上传页（与容器文档同域：`miniapp-sandbox.xiaohongshu.com`）。

页面会给出两步流程与**当前口令**。

### 步骤 2：按口令交给工作区 AI（仅在需要重新打包时）

1. 复制上传页第一步展示的**完整口令**（不要用手工保存的旧口令）
2. 发给当前工作区的 AI 助手
3. AI 会按口令下载对应版本 Skill、解压到指定目录、读取 `SKILL.md`，再校验、修复、打包

> 口令本身是操作指令。只把上传页当次给出的口令发给你信任的工作区。本项目已有合规产物时，可跳过这步，直接上传现有 zip。

### 步骤 3：上传 zip

1. 在上传页第二步选择 `shujing-minitool-v4.0.28.zip`
2. 等待页面解析包结构
3. 若提示文件类型、入口位置或体积问题，按提示修正后重传（不要靠改后缀绕过）

### 步骤 4：填写应用信息

按上传页实际字段填写，文案直接取《应用信息填写模板》：

- 名称：数境 · 四国远征
- 一句话简介：在战术地图上边答题边撤离的硬核知识游戏
- 详细简介：见模板
- 标签：益智 / 数学 / 策略 / 答题 / 单机
- 图标：`store/icon_512.png`
- 截图：`store/01_战场.png`、`02_烽火答题.png`、`03_战术地图.png`

> 分类下拉项以页面为准。没有"教育"时选最接近的益智/游戏类，并在简介首句保留"知识游戏"定位。

### 步骤 5：平台模拟器验证

在创服平台模拟器里从头走一遍：

1. 更新公告 → 首访说明
2. 进入战场 → 点地图移动 → 开箱答题
3. 答对、答错各一次，看反馈是否同帧出现
4. 打开战术地图 → 关闭
5. 撤离结算 → 回基地 → 交易站
6. 菜单 → 存档码导出（验证可复制/可读）

重点看：白屏、点了没反应、AI 入口未加白时是否给出提示。

### 步骤 6：Android 真机扫码

用 Android 手机扫码打开同一产物，检查：

- 触摸移动、点击热区是否够大
- 滚动与返回手势
- 软键盘是否遮挡输入
- 音效需用户手势后才能恢复（AudioContext 策略）
- 切后台再回前台，页面是否恢复

### 步骤 7：iOS 真机扫码

用系统 ≥ iOS 18.4 的 iPhone 扫码，检查：

- 刘海与底部横条的安全区
- `100vh` 布局是否被浏览器工具栏挤变形
- 滚动惯性
- localStorage 是否被容器清理（清掉后存档码能否恢复）

### 步骤 8：提交审核

三端验证通过后提交，审核备注直接用模板第 5 节内容。

审核时长与驳回口径平台未公开，以页面状态为准。

## 三、被驳回时

1. 按反馈定位：包结构 / 禁用能力 / 内容合规 / 素材不符
2. 改包后**递增版本号**（`tools/release.py` 会写进产物与 `version.json`）
3. 重跑 `python tools/check.py` 与审计脚本
4. 重新走模拟器 + 双端真机，再提审

不要只改截图或文案后重复提交同一产物。

## 四、发布后

- 保留：本次 zip、三张截图、审核备注、真机验证记录
- 每次发版重复：改包 → 审计 → 模拟器 → 双端真机 → 提审
- 关注：存档丢失反馈、AI 未开通提示、低端机卡顿
