## 六、已知风险（如实记录）

- **存档持久化**：游戏存档走 `localStorage`（已有 try/catch + `storageOK` 标志 + 面板提示）。容器文档将浏览器存储列为「兼容降级方案」，不保证持久。缓解手段已内置：**存档码**导出/导入（纯文本，可复制粘贴）依然可用。未改用 Storage JS API 的原因：它是异步接口，而游戏存档是同步热路径，改异步会动业务逻辑，违反「只替换被禁能力」原则。
- **AI 详解**：内测期需平台为 appId 加白，未加白时用户会看到「这个工具还没开通 AI 详解」。
- **性能未实测**：包体与代码量合规，但真机帧率/内存没有运行数据，须以真机验证为准。
