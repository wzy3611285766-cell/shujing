01

小红书对游戏内容的技术要求

小工具本质是离线 H5：所有资源打进 zip，容器加载后不联网。下列为硬性约束，违反任一項都可能导致白屏或审核驳回。

1.1 包体与体积门禁

项目规则本项目实测判定
zip 总包≤ 10 MiB（硬上限）；建议 ≤ 2 MiB0.67 MiB达标
单个 HTML / CSS / JS / JSON无硬上限；> 2 MiB 触发风险提示app.js 1.77 MiB达标
上述文本解压后合计无硬上限；> 5 MiB 触发风险提示约 1.89 MiB达标
单条 Base64解码后 ≤ 1 MiB；> 100 KiB 建议改为独立文件无内嵌大图达标
文件数量无限制，但只允许白名单类型2 个达标

注：app.js 已接近 2 MiB 提示线（1.77 MiB）。后续加内容时优先拆分为多个 .js 按依赖顺序引入，不要把 bundle 再增大。

1.2 允许的文件类型

可以打包

  • .html — 有且只有一个 index.html，必须在 zip 根目录
  • .css — 样式表
  • .js — 脚本，必须是经典脚本
  • .png .jpg .jpeg .gif .webp .svg — 图片
  • .woff .woff2 — 字体
  • .json — 小型静态数据，不得当数据库

不能出现

  • node_modules、.git、.DS_Store
  • *.map、构建配置（vite/webpack config）
  • 多套一层目录导致 index.html 不在根（如 dist/index.html）
  • 多个 HTML 页面站点（单页，视图用 JS 切换）

1.3 资源加载规则（容器 CSP）

资源允许禁止
脚本包内 <script src="./app.js">内联 <script>、行内事件 onclick、javascript:、eval / new Function、WebAssembly、外部域名 / data: / blob: 脚本
样式内联 <style>、行内 style、包内样式表外部域名样式表
图片包内图片、data:、blob:（选图预览）外部域名图片
字体仅包内字体文件外部域名字体
音视频仅包内媒体文件外部域名、data: / blob: 媒体源
iframe / object—全部禁止
三个最容易踩的坑 ① 脚本必须外置——容器 CSP 不含 unsafe-inline，内联脚本和 onclick 一律不执行；② 不要用 type="module"，离线 zip 下相对 import 解析不可靠，典型症状是“界面出来了但逻辑全死”；③ 不要写 <base href>，会破坏真机路径。

1.4 分辨率与适配

页面必须声明

  • <!DOCTYPE html>
  • lang="zh-CN"
  • charset="UTF-8"
  • viewport 含 width=device-width, initial-scale=1, viewport-fit=cover
  • 资源全部相对路径 ./assets/...

适配与安全区

  • 刘海 / 圆角屏用 viewport-fit=cover + env(safe-area-inset-*)
  • 容器统一控制导航栏、下拉刷新，包内不要自绘外壳
  • 视觉全屏用 CSS 布局实现，requestFullscreen 被禁用
  • 触摸手势用 touch* 或 Pointer Events

1.5 运行环境与兼容基线

维度要求本包处理
内核基线Android 8.1 出厂 WebView / Chrome 61纯 ES2017，无 ?. / ?? / 对象展开 / flat / replaceAll
脚本形态经典脚本，无 import / export单文件 bundle，node --check 通过
CSSChrome 61 基线层 + 能力检测增强53 处 clamp()/min()/max() 均有前置降级声明
iOS 最低版本iOS 18.4（在线文档更新）低版本设备无法保证运行，需在说明中提示
Storage API客户端 ≥ 9.46.0；文件系统 / 评论互动 ≥ 9.49本包未使用平台 Storage，走 localStorage + 存档码
AI 能力window.xhs.AI 内测期需 appId 加白未加白时返回 false 并显示人话提示

1.6 可用 / 禁用能力

可用

  • HTML / CSS / 标准 DOM 与事件
  • Canvas 2D；WebGL 1/2（受 DPR、纹理、draw call 预算约束）
  • alert() / confirm()（原生 UI）
  • <input type="file">（仅能选图片 / 视频）
  • getUserMedia（需用户手势 + 授权）
  • 包内音视频内联播放
  • window.xhs.AI（需加白，100 次/天/用户）

禁用（调用即异常或被拦截）

  • 联网：fetch / XMLHttpRequest / 外部资源
  • 实时通信：WebSocket / EventSource / WebRTC
  • 多线程：Worker / SharedWorker / Service Worker / SharedArrayBuffer
  • 定位、剪贴板、蓝牙 / USB / 串口、各类传感器
  • 全屏、window.open、window.prompt、外链跳转
  • 文件下载 a[download]、表单跳转提交、PWA 安装
  • eval / new Function / WebAssembly
本包已按禁用清单改写 云存档、远程识别、本地 OCR、剪贴板复制、文件导出、全屏按钮均已停用或移除；AI 讲解改走 window.xhs.AI。详细改写记录见 minitool/校验摘要.md。

05

上传与提审流程

小红书的小工具上传入口在创服平台的上传页。官方文档明确：从上小工具上传页开始，复制页面给出的当前口令给工作区 AI，由它按口令取对应版本 Skill、校验打包，再回到上传页第二步。字段与步骤以页面实际为准。

  1. 确认产物与版本

    确认 minitool/dist/index.html 内的 NEWS_VER 与公告内容一致（小工具版为 v4.0.28-3f17d760）。它和网页版的 653a052c 不同是正常的——小工具版不渲染「怎么开全屏」区块，卡片内容变了，哈希自然变。

    不要重新压缩本仓库的 zip 已是“压缩目录内容”的方式，index.html 在根。若要自己压，进入 minitool/dist 后压缩当前目录内容，别压缩 dist 文件夹本身。

  2. 进入小工具上传页

    打开小红书创服平台的小工具上传页（与容器文档同域：miniapp-sandbox.xiaohongshu.com）。页面会展示当前上传口令与两步流程，不要沿用手工保存的旧口令。

  3. 把口令交给工作区 AI（如需重新打包）

    复制上传页第一步的完整口令，发给当前工作区的 AI 助手。它会按口令下载对应版本 Skill、解压到指定目录、读取 SKILL.md，再做校验、修复与打包。

    口令等于操作指令。只把上传页当次给出的口令发给你信任的工作区；本项目已有合规产物时，可直接跳到下一步，不必重跑打包。

  4. 上传 zip 并填写应用信息

    在上传页第二步选择 minitool/shujing-minitool-v4.0.28.zip。按第 03 节填入名称、简介、标签；图标与截图用 minitool/store/ 内的文件，若页面提示尺寸不符，按提示等比导出。

  5. 平台模拟器完整验证

    上传后在创服平台模拟器里从头走一遍：公告 → 首访说明 → 进入战场 → 开箱答题 → 战术地图 → 撤离结算 → 存档码导出。重点看：是否有白屏、按钮是否点了没反应、AI 入口在未加白时是否给出提示。

  6. Android 真机扫码验证

    用 Android 手机扫码打开同一产物，验证触摸手感、滚动、返回、软键盘遮挡、音效恢复（需用户手势）、切后台再回前台是否正常。

    浏览器直跑不算数。官方规范明确：普通浏览器里跑通不能作为小工具功能与兼容性的验收依据。

  7. iOS 真机扫码验证

    用系统 ≥ iOS 18.4 的 iPhone 扫码验证同一产物。重点看安全区（刘海 / 底部横条）、100vh 布局、滚动惯性、以及 localStorage 在容器内是否被清理。

  8. 提交审核

    三端验证通过后提交，审核备注直接用第 03 节内容。审核时长与驳回口径平台未公开，以页面状态为准；被驳回时按反馈改包，版本号递增后重新走 04 节自检。

  9. 发布后回归

    通过后保留：本次 zip、三张截图、审核备注、真机验证记录。后续每次发版重复“改包 → 审计 → 模拟器 → 双端真机 → 提审”，不要只在一端验证。

06

已知风险与待你验证项

如实记录，不掩盖。这些不是靠改文档能解决的，需要真机数据或平台配置。

存档可能不持久

  • 容器把浏览器存储列为“兼容降级方案”，不保证长期保留
  • 未改用平台 Storage API：它是异步接口，而存档是同步热路径
  • 已内置兜底：存档码导出 / 导入（纯文本，可长按复制）

AI 讲解需加白

  • window.xhs.AI 内测期需平台为 appId 加白
  • 未加白会返回 AI_NOT_ALLOWED，界面显示“这个工具还没开通 AI 详解”
  • 配额 100 次/天/用户；需处理 AI_QUOTA_EXCEEDED / AI_CONTENT_BLOCKED

性能未实测

  • 包体与代码量合规，但真机帧率 / 内存没有运行数据
  • WebGL 场景在低端机的降级路径已存在，触发阈值未验证
  • 验收以模拟器 + 双端真机为准，不以本地 Chrome 为准

平台规则会变

  • iOS 最低版本、Storage / 文件系统版本门槛近期有更新
  • 上传口令每次以页面当次展示为准，旧口令会失效
  • 图标 / 截图规格未公开，提审前先看上传页提示
